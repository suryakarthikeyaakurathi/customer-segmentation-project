# Customer Segmentation Project

This project performs customer segmentation using Machine Learning (K-Means Clustering) and visualizes customer behavior using Power BI.

## Project Objectives
- Segment customers based on income and spending behavior
- Analyze customer demographics
- Identify customer spending patterns
- Generate business insights for targeted marketing

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Power BI

## Machine Learning Technique
- K-Means Clustering

## Dashboard Features
- Customer Cluster Distribution
- Income vs Spending Analysis
- Gender Distribution
- Customer Behavior Visualization

## Key Insights
- Cluster 2 contains the highest number of customers.
- Spending behavior varies significantly across income groups.
- Customer demographics help identify target audiences.
